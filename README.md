# Banque Misr Login App

A simple Banque Misr login screen built with Kotlin and Jetpack Compose.

## Features

- Login screen
- Show / hide password
- English & Arabic language support
- Arabic RTL support

## Built With

- Kotlin
- Jetpack Compose
- Android Studio

## Note

This is a learning project and is not an official Banque Misr application.
